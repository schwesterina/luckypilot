# LuckyPilot 2.0 Production Starter

Diese Version ist bewusst eine statische Webseite ohne npm-, pnpm-, React- oder
TypeScript-Build. Dadurch kann sie sofort und zuverlässig über GitHub Pages
veröffentlicht werden.

## Veröffentlichung

Der Workflow `.github/workflows/deploy-web.yml` veröffentlicht den Inhalt aus
`site/`.

## Enthalten

- responsive LuckyPilot-Webseite
- Suche und Kategorien
- Favoriten
- Teilnahme-Tracker
- Gewinn-Markierung
- mehrfach spielbare Aktionen
- eigene Einträge
- lokale Datensicherung
- Offline-/PWA-Grundlage
- Beispieldaten in `site/gewinnspiele.json`

## Wichtig

Die Beispieldaten müssen vor einer öffentlichen Bewerbung durch echte,
zulässige Gewinnspielquellen ersetzt werden.
